## הפעלה

1. פתחו את `index.html` בדפדפן Chrome, Edge, Firefox או דפדפן טלוויזיה התומך ב־JavaScript.
2. לחצו על **📺 מצגת לטלוויזיה** והשתמשו בחיצים למעבר ובמקש רווח לעצירה.
3. לייבוא התמונות של תשעת הסטיקרים, לחצו על **הוסף תמונות**. שמות קבצים מומלצים: `dad-1.png`, `dad-2.png`, `dad-3.png`, `mom-1.png` ... `sis-3.png`.
4. לתמונות מדויקות לכל משפט פתחו סטיקר ובחרו **תמונה לסטיקר זה**.
5. לחצו **גיבוי** כדי לקבל קובץ JSON עם התמונות שנוספו; לחצו **שחזור** במכשיר אחר.

## הצגה בטלוויזיה

- אפשר להעביר את קובץ `index.html` לטלוויזיה או לפתוח אותו ממחשב המחובר לטלוויזיה באמצעות HDMI.
- כדי לפתוח אותו מכל מכשיר ברשת הביתית ניתן לארח את התיקייה בשרת סטטי מקומי. ללא שרת/אחסון, הטלוויזיה לא תוכל לגשת לקובץ שבמחשב אחר רק לפי שמו.
- האתר אינו דורש ספריות JavaScript, גופנים מקוונים או חיבור אינטרנט להפעלה רגילה.
- קובצי התמונות נשמרים במסד IndexedDB של *אותו דפדפן*. כדי להעביר אותם למכשיר אחר משתמשים בקובץ הגיבוי.
- דפדפנים מסוימים מגבילים אחסון מקומי של קובצי `file://`. במקרה כזה יש לפתוח דרך שרת HTTP מקומי.

## מצב התמונות

תשעת האיורים שנוצרו קודם לכן בשיחה הוצגו כפריטי תמונה, אך לא נמסרו כקובצי מקור זמינים בתיקייה בעת בניית האתר. לכן חבילה זו כוללת תשעה עיצובים מובנים מבוססי HTML/CSS ואת כל המלל המדויק. היא **אינה כוללת** את תשעת קובצי ה־PNG המקוריים. האתר מוכן לקלוט אותם כשיהיו זמינים.

## זכויות ופרטיות

אין איסוף נתוני שימוש, שרת צד שלישי, התחברות או שיתוף אוטומטי של תמונות. הטקסטים בסדרה נכתבו בעבור הפרויקט הזה. אין להניח שאחסון מקומי בדפדפן הוא גיבוי ארוך טווח; מומלץ לייצא JSON.
